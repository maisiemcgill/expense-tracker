# Expense Tracker

A web application built with HTML, CSS and JavaScript that allows users to record and review their income and expenses.

## Overview

This project demonstrates my front-end development skills and my ability to use JavaScript to create an interactive application for managing financial records.

## Features

- Record income and expenses.
- Review recorded financial transactions.
- Display financial information in an organised interface.
- Interact with the application to manage entries.

## Technologies Used

- HTML5
- CSS3
- JavaScript
